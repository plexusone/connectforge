# v0.7.0

**Release Date:** 2026-11-06

## Highlights

- **A connection shows what it reaches.** A provider's validation can
  return `Details`, such as the sites or projects the credential can read.
  The service shortens them (up to 8 labelled lists of up to 25 values,
  with `More` counting the rest, control characters removed and long values
  cut) and keeps them in `Health.Details` after each successful check. A
  failed check keeps the last ones, so an interface can show what the
  connection reached when it last worked.

The release adds no breaking change. Stores keep health as one value, so
existing records read as before, with no details until their next check.

## Upgrading

Nothing is required. Providers that want to show what a credential reaches
set `provider.Result.Details`; they must never put a secret in them.

## Dependencies

- `modernc.org/sqlite` 1.61.1 and `github.com/jackc/pgx/v5` 5.12.0.

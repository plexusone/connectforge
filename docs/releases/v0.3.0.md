# v0.3.0

**Release Date:** 2026-10-13

## Highlights

- **Renamed to connectforge.** The module, package, tables and identifiers
  take the shorter name. There are no other changes.

## Breaking changes

| Before | After |
|---|---|
| `github.com/plexusone/connectionforge` | `github.com/plexusone/connectforge` |
| package `connectionforge` | package `connectforge` |
| tables `connectionforge_*` | tables `connectforge_*` |
| credential purpose `connectionforge.credential` | `connectforge.credential` |
| `CONNECTIONFORGE_TEST_POSTGRES_DSN` | `CONNECTFORGE_TEST_POSTGRES_DSN` |

Update imports and the alias, then `go get github.com/plexusone/connectforge@v0.3.0`.

A deployment that already holds data renames its tables, and re-seals its
credentials under the new purpose or has each connection reconnected, because
a credential is bound to its purpose when it is sealed.
